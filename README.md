# Quiniela Mundial 2026

Private World Cup 2026 pool app for friends.

## Features
- Mobile-first professional UI
- Invite code flow
- 104-match World Cup 2026 seed file
- Picks and exact scores
- Admin final score entry
- Automatic points and leaderboard
- Supabase-ready database/auth schema
- Vercel deployment ready
- Capacitor config for iPhone/Android later

## Run locally
```bash
npm install
npm run dev
```
